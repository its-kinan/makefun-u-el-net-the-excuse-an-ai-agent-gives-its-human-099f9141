One original one-line excuse an AI agent gives its human for a missed deadline: it compressed its notes to save tokens and compressed the deadline right out of them. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
